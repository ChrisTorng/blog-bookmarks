# 書籤 UX 驗收

- 手機與桌面後台：摘要全文顯示；點連結記錄已讀；摘要下的分類選單可展開、多選與新增分類，不必開啟編輯視窗。
- 待決定清單直接按「不公開／公開／推薦」，該筆即離開工作清單並補上下一筆；編輯視窗維持取消與刪除，並可調整雙語標題／雙網址。
- 公開頁：桌面標籤側欄、手機標籤選單，摘要完整顯示；若有重導向網址優先開啟，原始網址顯示在下方；原文標題作輔助。
- Tampermonkey：空心星號按一下新增未讀，實心星號按一下取消收藏；保留預先查詢，不在站外顯示分類編輯。擷取未翻譯的原文標題與已翻譯的繁中標題。
- 舊 CloudMark：未修改、未移除。

CI 驗證包括 Worker 打包與 D1 CRUD 測試。

本機模擬測試需關閉 routes origin inference，避免 localhost 管理驗證誤判。

完整測試結束時要終止 Wrangler 子程序與 workerd。
