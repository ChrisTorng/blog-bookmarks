# Public Site And RSS Contract

This is the data/API/RSS backend for **blog-bookmarks**. The public website layout is owned by [ChrisTorng/christorng.github.io](https://github.com/ChrisTorng/christorng.github.io), particularly `components/bookmarks`, `components/notes` and `components/ListWithCategories.tsx`. Do not create a separate public visual design here. The Worker handles `/bookmarks/api/*`, `/bookmarks/feed.xml`, `/bookmarks/sitemap.xml` and `/bookmarks/<slug>/`; other paths are forwarded to the GitHub Pages origin. Administrative UI is exempt from public visual parity.

## Cross-repository consistency

- Before changing any public presentation, route, title, category, RSS convention or feed content, check the main site and [blog-notes](https://github.com/ChrisTorng/blog-notes) for their corresponding behavior and update all affected repositories together.
- Public desktop/mobile header, category sidebar and mobile selector, typography, spacing, colors, links, responsive breakpoints, accessible labels and item cards must use the main site's conventions. Inspect both desktop and narrow-screen layouts.
- On a list page, the visible heading is `書籤` or `{category} · 書籤`. The root category option is `所有書籤`; the visible RSS link is `所有書籤 RSS` or `{category} · 書籤 RSS`. The feed's XML channel title adds ` | ChrisTorng 學習天地` after the visible RSS label, matching the site's HTML document-title separator.
- RSS `<item><link>` and permalink GUID use `/bookmarks/<slug>/`; never point to the old query-string preview unless an unmigrated record is encountered. The RSS item's complete HTML contains the externally linked Chinese title, original English title, Markdown-rendered summary, website/source information, localized category tags and recommendation/date metadata. Escape XML/HTML and preserve permalink stability after initial slug allocation.
- Public API dates are Taiwan-local calendar dates, intentionally excluding private processing/reading time. Feed pubDates may use deterministic monotonic synthetic seconds for same-day order, **not** real private timestamps; never claim synthetic seconds are true posting times. Keep newest-first feed order and check stability when new bookmarks arrive.

`src/views.js` is legacy, not the canonical public renderer. The public list is from `christorng.github.io/components/bookmarks/BookmarkPublicItem.tsx`; the permalink and RSS both use `src/public-content.js#bookmarkArticleHtml`. Any markup change must be mirrored and tested across all three. Never render public Markdown as plain escaped text or present an unlocalized tag label.
